# 🚗 Tesla Global Sales & Analytics Dashboard

An interactive Power BI dashboard tracking global revenue, delivery metrics, regional performance, and model-wise sales trends for Tesla.

## 📌 Project Preview
![Dashboard Screenshot](assets/dashboard_preview.png)

## 📊 Key Insights & Features
* **Executive KPI Summary:** Quick view of Total Revenue, Units Sold, Average Selling Price, and Production Delay Days.
* **Regional Distribution:** Donut chart analyzing market share across Europe, Asia, North America, South America, and Australia.
* **Model Rank & Trend Analysis:** Custom Ribbon Chart showing sales volume changes across vehicle lines over time.
* **Custom Theme:** Tailored dark/editorial layout styled with Tesla-inspired high-contrast color palettes.

## 🛠️ Tech Stack & Tools
* **BI Tool:** Microsoft Power BI Desktop
* **Data Source:** Vehicle delivery and analytics dataset (CSV)
* **Design/Theme:** Custom JSON Palette (`theme.json`)

## 🚀 How to View This Report
1. Download or clone this repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. (Optional) Re-apply `theme.json` via **View -> Themes -> Browse for themes**.
